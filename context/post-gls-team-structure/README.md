# Post-GLS team structure: publishing kit

| File | What it is |
| --- | --- |
| `confluence-page.md` | Page body to paste into Confluence |
| `diagrams/*.drawio.svg` | Six diagrams. Each is an SVG image with the draw.io model embedded, so it renders anywhere and opens editable in draw.io |
| `../post-gls-team-structure-proposal.md` | Working version with fuller reasoning and workspace references. Not for publishing |

Diagrams are generated by `tools/drawio_charts.py`. Regenerate with `python3 tools/drawio_charts.py`. Once the page is live and someone edits a diagram in Confluence, the Confluence copy becomes the source of truth. Do not regenerate over it.

## Before publishing: restrict the page

**OI30 is shared with StatusNeo.** Their onboarding page lives in the space. This page plans their roll-off and refers to SOW terms. Either:

- create it in OI30 with **page restrictions** (padlock icon, then "Only specific people can view or edit"), limited to Bain staff, or
- publish it in a Bain-only space and link to it from OI30 later.

Page restrictions are inherited by child pages, so a restricted parent also covers any follow-ups.

## Steps

1. Create the page and apply the restriction above **before** adding content.
2. Paste the body. In the editor choose **+ Insert, Markup**, select **Markdown**, and paste `confluence-page.md` without its first line. The title goes in the page title field.
3. For each `[Diagram: ….drawio.svg]` marker, replace it with the diagram:
   - **draw.io app installed** (type `/draw.io` in the editor to check): insert a draw.io diagram, choose **Import from device** and pick the matching `.drawio.svg`. It stays editable inline.
   - **No draw.io app:** type `/image` and upload the `.drawio.svg`. It shows as an image. To edit, open the attachment at app.diagrams.net and re-upload it with the same name.
4. Check the tables survived the paste, and remove the "Editing the diagrams" section if you used the draw.io app, since the Edit button makes it obvious.
