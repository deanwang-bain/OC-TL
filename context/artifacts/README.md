# Artifacts

Source documents handed to the Tech Lead outside Confluence — decks, spreadsheets,
generated HTML handoffs — kept so that any claim distilled into `context/` stays
traceable to what was actually received.

**These are not mirrored and not synced.** Unlike `confluence/`, nothing refreshes them.
If a newer version of an artifact arrives, replace the file and update the note that
cites it. Name files `YYYY-MM-DD-short-name.ext` using the date received.

| Artifact | Received | Distilled in |
| -------- | -------- | ------------ |
| `2026-09-03-opportunity-catalyst-journey-portal.html` | 2026-09-03 | [`../journey-portal.md`](../journey-portal.md) |

The journey portal is a single-file browser app: open it directly to get the swimlane
diagrams and Mermaid ER models, which the markdown distillation cannot carry.
