# Public opportunity scan: skill and samples

The public-data teaser for Opportunity Catalyst. Name a listed company and the skill builds an outside-in view of where the value sits against its peers, from public filings, results releases and management statements. You get an A1 poster, a PowerPoint deck, or both. Every output points to the full Opportunity Catalyst.

## Install

Download `public-opportunity-scan.skill` and add it in Claude under Settings → Capabilities → Skills, or open the file in Claude and choose Save skill. The deck option uses the Bain slides skill when it is installed, and a neutral template otherwise.

## Before sharing a sample outside the team

These samples were built in an environment that could search the web but not open pages. Every figure and quote was read from search-result extracts of the cited filings and releases, and each poster says so in its header. Check the figures against the documents before using them with a client.
