# Technical requests

Requests routed to the Tech Lead: access, infrastructure, libraries, design deviations,
schema changes, integrations.

One file per request, from `TEMPLATE.md`, named `YYYY-MM-DD-short-slug.md`. Log every
one in `REGISTER.md` so the queue is visible at a glance.

Triage process: `../checklists/tech-request-triage.md`.

Recommendations are prepared here; **the Tech Lead signs off.** The `Sign-off` section
stays blank until that happens.
