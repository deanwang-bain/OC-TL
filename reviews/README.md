# Reviews

Code review records for SN's OI 3.0 work. One file per review, from `TEMPLATE.md`,
named `YYYY-MM-DD-short-slug.md`.

**Review only.** Findings and rationale go here and into the PR conversation. Code is
never pushed to the OI 3.0 repositories from this workspace — see the role boundaries
in `../CLAUDE.md`.

Standards applied: `../checklists/code-review.md`.

Why records live here rather than only in the PR: they accumulate into precedent. When
the same finding recurs across sprints it stops being a review comment and becomes a
candidate rule in `../decisions/`, or a gap worth writing up in Confluence.
