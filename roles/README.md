# Roles

Role definitions and job descriptions produced by this workspace, for positions Opportunity Catalyst
needs that do not exist yet.

One file per role. These are **drafts for the Tech Lead and HR**, not posted adverts.
Where a draft names a grade it is a proposed fit against Bain's job series, not a
confirmed one; compensation band, location and employment terms are deliberately left
out because they are not this workspace's to set.

Where a role exists because of a decision recorded in `decisions/`, the file links back
to it. A JD written without that link tends to describe a person rather than a job.
