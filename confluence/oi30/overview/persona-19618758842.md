# Persona

[View in Confluence](https://bainco.atlassian.net/wiki/spaces/OI30/pages/19618758842)

Primary persona:
**“The accountable partner”**

*"I need to walk into a client meeting confident. I need to understand the numbers, challenge them, and own the story."*

Key needs:

- Control over key judgment calls — peers, lever selection, anchor choice — without doing everything manually
- Ability to drill into any number: source, reasoning, confidence level, and how to improve it
- Intelligent push-back from the tool — flag outliers, surface hypotheses, not just outputs
- Non-linear editing: go back and adjust peers or context mid-flow; only affected modules rerun
- Client-ready PPT export in Bain / ThinkCell format, with monitoring after export

Key friction today:

- Existing tools/processes are too linear
- No reasoning visibility
- Trust gap on numbers
- OI process takes 2-3 days today
