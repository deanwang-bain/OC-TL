# Data Source Catalogue

[View in Confluence](https://bainco.atlassian.net/wiki/spaces/OI30/pages/19839025154)

To give one agreed view of where Opportunity Catalyst data comes from, so that anyone using the platform's output can see what sits behind a number, and anyone building on it knows what is available and what is still missing.

**What we capture**

- **What the source is** and what kind of information it provides
- **Why we need it** — the question it helps answer
- **How we get it**, how often, and whether that is automated or manual today
- **How sensitive it is**, and what we are and aren't permitted to do with it
